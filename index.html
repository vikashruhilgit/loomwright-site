The agent starts coding before anyone agrees what done is

Chat-coding jumps into files. You get a pile of edits and a shrug. Launch Pad writes a brief (feasibility, file impact, subtasks) before Supervisor touches the repo.

/autonomous "the next thing your users can feel"

Two agents, one repo, a merge mess

Parallel chats overwrite each other. Workers run in git worktrees. Overlapping files wait. Merges are ordered. You get one pull request, not five conflicting branches.

You cannot walk away, and you also cannot trust auto-merge

Queue the work with /automate. Default: it parks a reviewed PR and tells you if a human is required. Desktop banners are on; --notify adds webhooks. Pass --auto-merge and it squash-merges only when the five-condition trusted gate holds. --trust-unprotected is the explicit escape hatch. Anything unreadable parks. It does not silently ship.

/automate "the remaining shop tickets" --auto-merge

The mill forgets your house. Every run starts cold

Write rules once with /rules. /setup and committed .supervisor/config.json make the mill behave the same on a clone. /dreaming proposes lessons; you accept item by item. Harvested rules go out as a pull request. It gets smarter. It never self-trusts.
